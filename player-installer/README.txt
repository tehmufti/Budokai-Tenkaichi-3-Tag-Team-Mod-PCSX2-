TAG TEAM MOD - WINDOWS - START HERE / EMPIEZA AQUI

ENGLISH
1. Extract the entire ZIP to a folder.
2. Open Install.cmd and choose English or Spanish.
3. Select your ISO, PCSX2 executable (2.6.0 or newer) and a new installation folder.
   Setup uses the BIOS your PCSX2 already uses; it asks for one only if it finds none.
4. When setup finishes, open Play.cmd in that new folder.
Press Select at the main menu for Modded Modes.
Modes chosen from the original menu play normally.
Settings: Modded Modes > Mod Settings (controller) or Mod settings.cmd (desktop);
both have every setting.
Switch between your BT3 USA, Europe and Japan ISOs (or BT4 English and Spanish):
Mod settings.cmd > Game disc.

You need Windows x64, your own BT3 USA / Europe / Japan or BT4 B14 REV2 ISO,
your own PS2 BIOS and an extracted PCSX2 2.6.0 or newer, but not 3.x.
Use a stable release (2.6.0-2.6.3 or 2.8.0-2.8.2; 2.8.2 recommended);
other 2.x builds install with an untested-version notice.
Setup installs missing Python/Visual C++ prerequisites when WinGet is available.
PCSX2 download and full instructions: setup/README.md.
Leave the setup folder intact; you do not need to open its other files.
BT4 support is experimental; not every character/move has been playtested.
The European BT3 disc (SLES-54945) runs at 50 Hz, like the original game.
The Japanese BT3 disc (SLPS-25815) confirms with Circle in its own menus.

If setup stops, it prints a block that starts with a code like [TTM-BIOS-02]
and says what to fix; nothing is changed before all checks pass. Run
Install.cmd again with the same folder: an unfinished attempt is renamed
"Tag Team Mod (failed <date>)" (never deleted), and an existing installation
is kept (the new one goes beside it and setup offers to copy your memory cards
and mod settings; PCSX2 settings and savestates stay in the old folder).
Setup logs: %LOCALAPPDATA%\TagTeamMod\logs.
Opened Install.cmd inside the ZIP (TTM-ZIP-01)? Extract the whole ZIP first.
"Windows protected your PC"? More info > Run anyway.
If Play fails, run Check installation.cmd in your installation folder first.
The Play window stays open after an error; failure reports are in
game\analysis\failures. Moved the ISO? Play offers to find it.
Report the mod/PCSX2 versions, mode, fighters, stage and steps that caused it.
Copy the block with the code. Do not share ISO, BIOS or saves.

ESPANOL
1. Extrae el ZIP completo en una carpeta.
2. Abre Install.cmd y elige el idioma.
3. Elige tu ISO, el ejecutable de PCSX2 (2.6.0 o posterior) y una carpeta nueva.
   El instalador usa la BIOS que ya usa tu PCSX2; solo la pide si no encuentra ninguna.
4. Al terminar, abre Play.cmd en la nueva carpeta.
Pulsa Select en el menu principal para abrir los modos del mod.
Los modos del menu original funcionan como en el juego normal.
Ajustes: Modos del mod > Ajustes del mod (mando) o Mod settings.cmd (escritorio);
ambos tienen todos los ajustes.
Cambia entre tus ISO de BT3 de EE. UU., Europa y Japon (o BT4 en ingles y espanol):
Mod settings.cmd > Disco del juego.

Necesitas Windows x64, tu propia ISO de BT3 USA / Europa / Japon o BT4 B14 REV2,
tu BIOS de PS2 y PCSX2 2.6.0 o posterior extraido, pero no 3.x.
Usa una version estable (2.6.0-2.6.3 o 2.8.0-2.8.2; se recomienda 2.8.2);
otras 2.x se instalan con un aviso de version no probada.
El instalador obtiene Python y Visual C++ si faltan y WinGet esta disponible.
Descarga de PCSX2 e instrucciones completas: setup/LEEME.md.
Conserva la carpeta setup completa. No necesitas abrir sus otros archivos.
BT4 es experimental; no se han probado todos los personajes y ataques.
El BT3 europeo (SLES-54945) funciona a 50 Hz, como el juego original.
El BT3 japones (SLPS-25815) confirma con Circulo en sus propios menus.

Si el instalador se detiene, muestra un bloque que empieza con un codigo como
[TTM-BIOS-02] e indica que corregir; no cambia nada hasta superar todas las
comprobaciones. Vuelve a ejecutar Install.cmd con la misma carpeta: el intento
sin terminar se renombra "Tag Team Mod (failed <fecha>)" (nunca se borra) y una
instalacion existente se conserva (la nueva se crea junto a ella y el
instalador ofrece copiar tus tarjetas de memoria y ajustes del mod; los ajustes
y estados guardados de PCSX2 se quedan en la carpeta anterior).
Registros del instalador: %LOCALAPPDATA%\TagTeamMod\logs.
Abriste Install.cmd dentro del ZIP (TTM-ZIP-01)? Extrae antes el ZIP completo.
"Windows protegio su PC"? Mas informacion > Ejecutar de todas formas.
Si falla Play, ejecuta primero Check installation.cmd en tu instalacion.
La ventana de Play sigue abierta tras un error; los informes de fallo estan en
game\analysis\failures. Moviste la ISO? Play ofrece buscarla.
Indica las versiones del mod y PCSX2, el modo, los personajes, el escenario
y los pasos para reproducir el error. Copia el bloque con el codigo.
No compartas tu ISO, BIOS ni partidas guardadas.
